# Contribution and evidence boundaries

Keep changes small and reproducible. Run the unit tests and a smoke benchmark before proposing code changes. If statistical assumptions change, update METHOD.md and rerun the recorded benchmark rather than mixing metrics from different models.

This repository began on 25 September 2026 as an educational prototype. Do not present it as a previous publication, completed doctoral research, institutional collaboration, biological validation, or a clinical tool. Contributor roles should describe reviewed work actually performed; no collaborators or advisers are named without a verified contribution and permission.

Use synthetic identifiers in the default benchmark. Do not commit private data, credentials, patient information, application documents or personal correspondence. Any future public-data analysis must document its exact source, access conditions, preprocessing and evidence limits separately from the synthetic run.

No human-reviewed biological labels exist in the current repository. Future review-ready annotations must be marked `pending_human_review` until an identified review process is completed.
